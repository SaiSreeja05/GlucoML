{% elif section.type == "model" %}

How {{ section.title }} Calculates Glucose

{% if section_name == "linear" %}

Linear Regression learns a relationship between input features and glucose.

ŷ = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

The model multiplies each input feature by its learned coefficient and adds them together with the intercept.

{% elif section_name == "ridge" %}

Ridge Regression is Linear Regression with L2 regularization.

Cost = Σ(y − ŷ)² + αΣw²

The first part measures prediction error. The second part penalizes large coefficients.

In this project, α controls the strength of regularization.

{% elif section_name == "lasso" %}

Lasso Regression is Linear Regression with L1 regularization.

Cost = Σ(y − ŷ)² + αΣ|w|

Lasso adds a penalty based on the absolute value of coefficients. Some coefficients can become zero.

{% elif section_name == "gradient-boosting" %}

Gradient Boosting builds trees sequentially. Each new tree attempts to reduce the errors made by the previous trees.

New Prediction = Previous Prediction + Learning Rate × New Tree
{% elif section_name == "xgboost" %}

XGBoost builds decision trees sequentially and minimizes prediction loss together with regularization.

Objective = Loss + Regularization
{% elif section_name == "lightgbm" %}

LightGBM uses gradient boosting and builds trees efficiently by selecting useful splits that reduce prediction error.

New Prediction = Previous Prediction + Tree Contribution
{% endif %}

Model Evaluation Calculations

These metrics are calculated from the actual and predicted glucose values in the test dataset.

MAE {{ metrics.mae }} Average absolute error
MSE {{ metrics.mse }} Average squared error
RMSE {{ metrics.rmse }} Square root of MSE
R² {{ metrics.r2 }} Explained variation

Metric Formulas

Error = Actual Glucose − Predicted Glucose

MAE = Σ|Actual − Predicted| / n

MAE is the average absolute difference between actual and predicted glucose.

MSE = Σ(Actual − Predicted)² / n

MSE squares every error before taking the average.

RMSE = √MSE

RMSE gives the prediction error in the same units as glucose.

R² = 1 − SSres / SStot

R² represents how much variation in glucose is explained by the model.

Logistic Regression Calculation

Logistic Regression first calculates a weighted sum of the input features.

z = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

The weighted sum is converted into a probability using the sigmoid function.

P = 1 / (1 + e⁻ᶻ)

If the probability is at least 0.5, the predicted class is 1. Otherwise, the predicted class is 0.

Confusion Matrix Calculation

True Positive (TP) = {{ logistic_metrics.tp }}

True Negative (TN) = {{ logistic_metrics.tn }}

False Positive (FP) = {{ logistic_metrics.fp }}

False Negative (FN) = {{ logistic_metrics.fn }}

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision = TP / (TP + FP)

Recall = TP / (TP + FN)

F1 = 2 × Precision × Recall / (Precision + Recall)
